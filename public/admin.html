Poster & Background Art

Every day, this server pulls today's schedule for each league, fetches every team's/fighter's logo ahead of time, and builds the actual finished poster/background pictures in advance - so nothing has to be fetched from ESPN or assembled the first time someone views it. Use this button to run that same check right now - it re-pulls each league's live schedule (so a postponement or delay shows up immediately too) and rebuilds today's pictures, including any logo that changed.

EPG Editor

Choose which of epgshare01.online's XMLTV feeds this server keeps fetched and cached. This does not override anyone's EPG by itself - each enabled source just becomes available for a user to pick, per channel, in place of their provider's own guide. Every source you enable here adds an extra download + parse to the M3U refresh schedule above, so pick only what you actually need for your users' channel lineups (a per-country/category file, not the ~200MB combined one, unless you really need it).

Presets

Import a user's exported settings file (from their dashboard's Sources > Export/Import panel), give it a name and an icon, and save it as a preset. Captures everything about their setup - leagues/categories, EPG overrides, channel exclusions, and dashboard preferences (home visibility, sport order, catalog names, name/title format) - except credentials and their timezone, which an export never contains.

A preset added or changed by a code update (built-in ones included) starts off and greyed out below until you switch it on - that's also when you'll be asked about any EPG sources it needs.
